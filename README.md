# 🏢 AuraProp AI — Multi-Property Operations Suite

> **State-of-the-art Multi-Family & Commercial Real Estate Operations Platform with Multimodal AI Triage, In-Document Lease Q&A, and Role-Based Access Control.**

---

## 🌟 Key Features

### 1. 🛡️ Role-Based Access Control (RBAC) & Authentication
- **Step 1: Sign Up, Step 2: Login Flow** with role selection:
  - **Property Manager:** Executive portfolio KPIs, automated 60-day renewal offers, vendor dispatch desk, and immutable compliance audit logs.
  - **Resident / Tenant:** Simplified resident suite with rent payment, AutoPay management, 5-stage work-order progress bar, and emergency water-shutoff instructions.
  - **Certified Contractor:** Live emergency job queue, site lockbox entry codes (`#4819`), progression milestones (`Accept` → `In Progress` → `Resolved`), and Net-7 direct invoicing.
- **1-Click Testing Shortcuts:** Instantly log in as any role for fast interactive evaluation.

### 2. ⚡ AI-Powered Maintenance Triage (`AuraVision™`)
- **Multimodal Computer-Vision Diagnostics:** Inspects uploaded tenant photos to identify liquid pooling, ruptured supply lines, HVAC capacitor failures, and electrical arcing.
- **Risk & Urgency Scoring:** Calculates urgency score (`98/100 CRITICAL`) and isolates structural water ingress risks.
- **Automated Vendor Matching:** Auto-pairs with licensed, insured contractors (e.g. Apex 24/7 Rapid Response, 4.95★).
- **Interactive 5-Stage Timeline:** `Requested` → `AI Triaged` → `Contractor Assigned` → `In Progress` → `Resolved`.

### 3. 📄 Smart Leasing & Secure Document Vault (`AuraLease™`)
- **PDF-Style Lease Viewer:** Digital contract viewer with legal letterhead, signatures, and numbered clauses.
- **AI In-Document Citation Highlighting:** Ask natural language questions like *"What is the late fee policy?"* or *"Can I bring a pet?"* — the AI highlights the exact clause and auto-scrolls to it.

### 4. 💬 Resident Communications & AI Reply Drafting
- Two-pane communication center with tenant inbox threads.
- **✨ AI Draft Reply:** Context-aware reply generator supporting 3 selectable tones:
  1. *Empathetic & Rapid Action (Recommended)*
  2. *Formal & Policy-Compliant*
  3. *Concise Mobile Dispatch*

### 5. 💳 Payments, Rent Ledgers & Automated Reminders
- Multi-unit rent ledger tracking paid, upcoming, and delinquent balances.
- Automated AI SMS/email reminder toggles.
- PCI-compliant payment gateway stub supporting **ACH Direct Debit** ($0 fee) and **Credit/Debit Cards**.

### 6. 🔒 SOC-2 Compliance & Immutable Audit Trails
- Chronological logs recording human and autonomous AI actions with SHA-256 cryptographic integrity hashes.

## 🚀 Tech Stack

- **Frontend Framework:** React 19 + Vite 8
- **Styling & Design System:** Tailwind CSS v4, Plus Jakarta Sans, Inter
- **Icons:** Lucide React
- **Theme:** Enterprise Light Theme (`#F8F9FA` canvas background, `#FFFFFF` cards, Royal Blue `#1D4ED8` primary)

## 💻 Local Installation & Setup

```bash
# Clone the repository
git clone https://github.com/Muhammadislam776/AI-Property-Management.git

# Navigate into project directory
cd AI-Property-Management

# Install dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173/` in your browser.
